## Escopo

O projeto combina Python, `unittest`, `pytest`, TIR Framework, Selenium/WebDriver e PO-UI para automatizar rotinas tradicionais e telas Angular do Protheus.

Os documentos descrevem o estado observado do repositorio em agosto de 2026. Os testes dependem de um ambiente Protheus acessivel e nao sao substituidos por testes unitarios locais.
